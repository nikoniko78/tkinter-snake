# tkinter-snake

I worked very hard on this. Enjoy!

If you use Windows, you may to download 'sgame_linker.py'. It allows you to search 'sgame' into your search bar and open it from there instead of just file explorer, as it bugs out when you try to search for it. Place it in the same folder/directory as the game itself.

As for mods, put them in the folder called 'snakemods'. When you open the main game, it will create this folder for you. To make your own mods, there are hooks in the main code for you to use. Make sure to end you file name with '_smod.py' to make it compatible.

No AI (Artificial Intelligence) was used on this project except to put comments in mods, the main game, and the linker file so that anyone wishing to modify it can do so easily. I know my code is probably a mess, and I apologize for that. 

You will need to install Python 3.13.6 or later to play this game.

I encourage you to make your own mods, as I put hooks, and even a 60fps engine in the code just for mod compatibility.

Whatever directory or folder you put the game in will be the one the game saves your high scores to and sets up in. I recommend you put the game in a folder/directory you will remember.

Thanks for playing my game! -Remi
